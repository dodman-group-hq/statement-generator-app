How it works

01

Prepare your Word template

Write your statement as a normal Word document, and mark the parts that change per person with double curly braces, e.g. {{ '{{ name }}' }} or {{ '{{ balance }}' }}. Every placeholder in the template must have a matching column in your spreadsheet.

02

Prepare your Excel spreadsheet

One row per person. Column headers must exactly match your template's placeholders (spaces in a header become underscores automatically, so a Full Name column matches {{ '{{ Full_Name }}' }}). Two columns are required regardless of what else is in your template:

  • An ID column — one of id, client id, member id, or id number
  • A name column — one of name, client name, or member name

The name is used to name each output PDF, and the ID doubles as that person's password if you turn on password protection.

03

Create an account and an API key

Sign up, then create an API key from your dashboard. The key is shown once, so copy it somewhere safe. Open the generator page, paste your key, upload your template and spreadsheet, and choose whether to password-protect each PDF with that person's own ID.

04

Download your statements

Watch the progress bar while your statements are generated, then download every PDF in a single zip — each one named after the person it belongs to.
